# Sistema de Compra de Entradas de Cine
Proyecto en Java

## Patrones de diseño utilizados
1. Factory Method (Creacional): permite crear entradas normales y VIP
2. Decorator (Estructural): permite agregar palomitas y bebidas
3. Strategy (Comportamiento): permite aplicar diferentes descuentos

## Ejecución
El programa utiliza datos que ya definimos y funciona por terminal

Compilar:
javac Main.java

Ejecutar:
java Main

## Funcionamiento
El programa realiza dos compras:

- Entrada VIP con palomitas, bebida y descuento de estudiante.
- Entrada normal sin descuento.

No requiere librerías externas.
